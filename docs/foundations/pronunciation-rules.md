本页整理法语字母、音素和常见拼读规则。

## 基础发音规则

- 'e' 在结尾不发音
- 'h' 永远不发音
- 两个相同字母只发一个字母的音
- 结尾的辅音字母不发音，除'c', 'f', 'l', 'r' 外


## 字母组合的发音

| 字母组合 | 发音 | 例词 |
|---|---|---|
| on |   | bonjour bon  mon  C’est bon |
| en  em  an  am |   | enfant  enchanté |
| ai |   | faire  Je t’aime |
| ch |  | Chine  chinois |
