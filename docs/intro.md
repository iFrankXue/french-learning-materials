# 欢迎来到法语学习资料库

## 如何使用本站

- 从“基础入门”建立发音、词汇和语法基础。
- 在“专项提升”中按听、说、读、写查找练习材料。
- 通过“学习工具”集中寻找词典、语料库和实用网站。
