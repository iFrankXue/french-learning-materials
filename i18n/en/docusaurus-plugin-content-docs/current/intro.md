# Welcome to the French Learning Library

This site will collect, review, and organize useful resources for learning French. The first version establishes a clear structure that can grow with the content.

## How to use this site

- Start with “Foundations” for pronunciation, vocabulary, and grammar.
- Practice a specific area under “Core skills.”
- Find dictionaries, corpora, and useful sites under “Learning tools.”

:::info Content in progress

These pages currently provide the structure. The navigation will update automatically as new content is added.

:::
